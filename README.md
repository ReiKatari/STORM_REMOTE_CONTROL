<h1 align="center">STORM REMOTE CONTROL</h1>

## **О проекте**
STORM REMOTE CONTROL — высокопроизводительный программный комплекс для защищённого удалённого доступа, управления рабочим столом, трансляции экрана и двусторонней передачи файлов между компьютерами под управлением Windows по прямому P2P-каналу и через интернет.

## **Происхождение и форки**
Оригинальная разработка в составе экосистемы STORM SOFT.

## **Технологический стек**
- **Платформа и фреймворк**: .NET 10.0, WinUI 3 (Windows App SDK 2.1.3)
- **Сетевой стек**: P2P UDP Hole Punching, STUN (RFC 5389), WebSocket JSON-сигнализация
- **Криптография**: Сквозное шифрование AES-256-GCM, обмен ключами ECDH P-256, аутентификация HMAC-SHA256
- **Видеозахват и сжатие**: Windows.Graphics.Capture API, Media Foundation аппаратное кодирование (NVENC / AMF / QSV), тайловая JPEG дельта-компрессия
- **Интерфейс**: Объёмный 3D-дизайн с тактильной отдачей, поддержка 8 визуальных тем и 6 языков интерфейса

## **Ключевые возможности**
- **Удалённый рабочий стол высокой чёткости**: Плавная передача видеопотока до 144 FPS с адаптивным битрейтом и минимальной задержкой.
- **Двухоконный файловый менеджер**: Быстрое перемещение, копирование и управление файлами между локальным и удалённым ПК с поддержкой горячих клавиш.
- **Интегрированный защищённый чат**: Обмен текстовыми сообщениями внутри активной сессии без использования сторонних мессенджеров.
- **Прямой ввод и системные комбинации**: Передача мыши, клавиатуры, специальных сочетаний клавиш (Ctrl+Alt+Del, Alt+Tab, Win).
- **Синхронизация буфера обмена**: Двусторонний обмен текстом в реальном времени.
- **Единая система оформления**: Мгновенное переключение 8 тем оформления (STORM DARK, STORM NIGHT, STORM DAY, STORM MIDNIGHT, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY, STORM WARHAMMER 40K).
- **Полная мультиязычность**: 100% локализация интерфейса на 6 языков (русский, английский, немецкий, французский, китайский, японский).

## **Поддерживаемые платформы**
- Windows 10 (версия 21H2 / сборка 19044 и новее), Windows 11 (x64, ARM64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_REMOTE_CONTROL_1.0.0_Setup.exe` или портативный архив `STORM_REMOTE_CONTROL_1.0.0.zip` из раздела **Releases**.
2. Запустите программу, скопируйте ваш 9-значный уникальный ID и передайте его партнеру для подключения или введите ID удалённого ПК в поле «Удаленное управление».
